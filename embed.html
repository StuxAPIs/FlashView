Embed Ruffle on your site

FlashView hosts a copy of Ruffle you can load from your own pages. Add one script tag and your old Flash embeds play again.

Quick start

Put this anywhere on a page with Flash content. Ruffle finds every <object> and <embed> that loads an SWF and replaces it with a player.

<script src="https://flash.stuxapis.net/ruffle/ruffle.js"></script>

Ruffle loads its WebAssembly from FlashView too, so there's nothing else to host. Your SWF files stay on your own site.

Add a player from JavaScript

For a page without existing embeds, create a player yourself:

<div id="game" style="width:800px;height:600px"></div>
<script src="https://flash.stuxapis.net/ruffle/ruffle.js"></script>
<script>
  const player = window.RufflePlayer.newest().createPlayer();
  player.style.width = '100%';
  player.style.height = '100%';
  document.getElementById('game').appendChild(player);
  player.ruffle().load('/games/my-game.swf');
</script>

Options

Set window.RufflePlayer.config before the script tag to change how every player behaves. A few useful ones:

<script>
  window.RufflePlayer = window.RufflePlayer || {};
  window.RufflePlayer.config = {
    autoplay: 'on',            // 'auto', 'on' or 'off'
    unmuteOverlay: 'hidden',   // or 'visible'
    letterbox: 'on',           // 'fullscreen', 'off' or 'on'
    backgroundColor: '#000000',
    splashScreen: false
  };
</script>
<script src="https://flash.stuxapis.net/ruffle/ruffle.js"></script>
OptionWhat it does
autoplayauto plays when the browser allows it; on always tries; off waits for a click.
unmuteOverlayWhether to show the “click to unmute” overlay when sound is blocked.
letterboxBlack bars to keep the movie's shape: on, off or fullscreen only.
backgroundColorOverrides the movie's own background colour.
splashScreenWhether to show Ruffle's loading screen.
polyfillsfalse stops Ruffle replacing existing embeds, if you only want players you create.

The full list is in Ruffle's documentation.

Which version

FlashView serves Ruffle (loading…), a stable release. We check for new releases every week and update after testing. If you need a fixed version, or a lot of traffic, host Ruffle yourself: download the self-hosted build and upload its files next to your pages.
